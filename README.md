# ⚙ 齿轮传动配组台（Gear Matching Bench）

给定**目标传动比**、**1～3 级传动**以及各级主动/从动齿轮的**齿数范围与锁定齿轮**，
枚举并剪枝全部可行组合，使用 **bigint 精确分数**累计总传动比，按
**相对误差 → 总齿数 → 逐级齿数字典序**稳定排名，展示前 20 个方案的
逐级比值、总误差与简化啮合示意图。约束变化后自动防抖重算，方案可一键复制。

技术栈：**React 18 + TypeScript + Vite 5**，求解在 **Web Worker** 中进行，不阻塞界面。

## 一条命令启动（Docker，含依赖安装与构建）

```bash
docker compose up --build
```

启动后在浏览器访问：

> **http://localhost:8080**

端口在 `docker-compose.yml` 中映射（宿主机 `8080` → 容器 Nginx `80`），
若 8080 被占用，把 `"8080:80"` 改成例如 `"9090:80"` 即可。

停止：

```bash
docker compose down
```

## 使用说明

1. **目标传动比**：输入正数，支持
   - 小数：`6`、`6.25`
   - 分数：`12/7`、`12:7`
   - 带分数：`1+2/3`
2. **级数**：1～3 级，可在任意级之后插入或删除。
3. **各级齿数范围**：分别设置主动轮、从动轮的最小/最大齿数（合法齿数 8–240，单边跨度 ≤ 120）。
4. **锁定齿轮**：勾选“锁定”后该齿轮固定取“最少齿”的值，不再枚举。
5. **最小齿差**：每级 `|从动齿数 − 主动齿数|` 低于该阈值的齿对直接剔除（避免齿数过近的配组）。
6. 右侧实时给出前 20 个方案；每张卡片可展开**啮合示意图**、**复制方案**，也可一次复制全部。

> 说明：本工具枚举的是各级 (主动齿数, 从动齿数) 的离散组合，传动比定义为
> 级比 = 从动齿数 / 主动齿数；总传动比 = 各级级比连乘（与“减速 = 从动/主动”的常见口径一致）。

## 求解器设计（`src/lib/solver.ts`）

- **精确分数**：每个齿对的级比保存为 `bigint` 分子/分母，DFS 中只做整数乘法连乘，
  到达叶节点才约分，全程无浮点误差；比较（含相对误差）全部走交叉相乘。
- **枚举与剪枝**：
  - 建表阶段按最小齿差过滤无效齿对，并按 `(z1, z2)` 升序排列；
  - 预计算每一级起“后缀各级乘积”的可达区间 `[suffixMin, suffixMax]`；
  - DFS 每选一个齿对，若 `当前乘积 × 剩余区间` 不可能覆盖目标（偏大或偏小），整支剪枝；
  - 目标落在全局可达区间之外时自动退化为“全枚举找最接近解”，不会空结果。
- **稳定排名**：比较器依次比较
  1. 相对误差 `|i − i*| / i*`（精确分数，升序）；
  2. 全台总齿数（升序）；
  3. 逐级 `(主动齿, 从动齿)` 的字典序（升序）。
  
  叶节点按“有序插入前 K”维护前 20 名，无需对全量结果排序。
- **即时重算与取消**：输入变化经 120ms 防抖后发给 Web Worker；
  Worker 每 2¹⁶ 次内层循环向事件循环让步并检查“代际令牌”，
  新约束到来时旧枚举立即作废，UI 永不卡顿。
- **枚举预算**：可行叶节点超过 2000 万时停止并在状态栏提示“结果可能非全局最优”。

## 项目结构

```
.
├── Dockerfile               # 多阶段构建：node 构建 -> nginx 托管
├── docker-compose.yml       # 一条命令 up --build，端口 8080:80
├── nginx.conf               # SPA 回退与静态资源缓存
├── index.html
├── package.json
├── tsconfig.json
├── vite.config.ts
└── src
    ├── main.tsx
    ├── App.tsx              # 约束面板 + 结果区组合、输入校验
    ├── types.ts             # 表单类型与默认值
    ├── hooks
    │   └── useGearSolver.ts # Worker 生命周期 / 防抖 / 代际令牌
    ├── lib
    │   ├── fraction.ts      # bigint 精确分数：约分、比较、误差、解析
    │   ├── solver.ts        # 枚举 + 区间剪枝 + 前 K 排名（核心）
    │   ├── solverWorker.ts  # Worker 包装与取消
    │   └── format.ts        # 方案文本复制与数字格式化
    ├── components
    │   ├── StageCard.tsx    # 单级范围与锁定配置
    │   ├── NumberField.tsx
    │   ├── SolutionCard.tsx # 逐级比值、误差、复制、示意图开关
    │   └── GearDiagram.tsx  # 简化啮合示意（SVG）
    └── styles
        └── index.css
```

## 浏览器要求

需要原生支持 BigInt 的现代浏览器（Chrome/Edge/Firefox/Safari 近年版本均可）。
