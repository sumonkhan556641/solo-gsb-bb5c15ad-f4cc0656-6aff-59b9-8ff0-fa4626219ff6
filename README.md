# 齿轮传动配组台

多级定轴齿轮传动配组工具：给定目标传动比与各级齿数范围（可锁定齿轮），自动枚举、剪枝并排名可行配齿方案，展示逐级比值、总误差与简化啮合示意。

- React 18 + TypeScript + Vite 构建
- 求解器运行在 Web Worker 中，约束变化后 **150 ms 防抖即时重算**，界面不卡顿
- 总传动比以 **bigint 精确分数** 逐级累计，排名无浮点抖动
- 剪枝：比值区间下界剪枝 + 倒数第二级“最近邻比值”精确下界 + 末级二分窗口枚举
- 排名规则：**相对误差 → 总齿数 → 齿数组合字典序**，稳定输出前 20 个方案
- 一键复制单个方案或全部方案（纯文本）

## 传动比约定

- 级比：`i_k = 从动齿数 / 主动齿数`
- 总传动比：`i = i_1 × i_2 × … × i_k`
- 目标支持：整数（`8`）、小数（`3.5`）、分数（`24/17`）、百分比（`0.5%`）
- 每级排除 `|z从动 − z主动| < 最小齿差阈值` 的组合

## 功能说明

| 区域 | 说明 |
| --- | --- |
| 目标传动比 | 整数 / 小数 / 分数 / 百分比均可 |
| 传动级数 | 1～3 级切换 |
| 齿数范围 | 每级分别设置主动轮、从动轮齿数上下限（8～1000） |
| 锁定齿轮 | 填入齿数即将该级该轮锁定为固定齿数（留空不锁定） |
| 最小齿差 | 全局阈值，齿差低于该值的级组合直接排除 |
| 硬误差上限 | 可选，仅保留相对误差不超过该百分比的方案 |
| 方案卡片 | 排名、总传动比、相对误差、总齿数、逐级齿对/级比/齿差、啮合示意与复制按钮 |

啮合示意中：蓝色为主动轮、琥珀色为从动轮，啮合对的节圆相切；级间以“同轴联动”短轴连接，表示两级共用同一根轴（上一级从动轮与下一级主动轮同轴）。

## 求解器

核心位于 `src/lib/`：

- `frac.ts`：bigint 分数（乘除、比较、约分、相对误差、目标解析）
- `solver.ts`：枚举与剪枝
  1. 每级枚举全部齿对，应用范围 / 锁定 / 齿差约束；同一约分比值只保留 `(齿数和, z主动, z从动)` 字典序最小的齿对；
  2. DFS 按“理想级比对数距离”启发式排序，尽早命中优质方案以收紧 Top-20 截断；
  3. 内部级用后缀乘积区间算误差下界剪枝；倒数第二级用二分最近邻得到更强的精确下界；末级只枚举截断窗口内的连续候选；
  4. 节点预算 2000 万，超限会标记“结果可能被截断”；
  5. 最终按 **相对误差、总齿数、齿数组合字典序** 稳定排序，返回前 20 个。
- `solver.worker.ts`：Worker 入口，避免重算阻塞 UI
